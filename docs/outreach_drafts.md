## 8. Code for Romania

**Canal:** contact@code4.ro (code4.ro)
**Subiect:** API deschis cu voturile nominale din Parlament

Bună ziua,

Sunt Denis, fac LaButoane (la-butoane.ro), un proiect independent care adună voturile nominale din Parlament de pe cdep.ro și senat.ro.

Datele sunt publice printr-un API read-only, fără cheie și fără cont, în JSON sau CSV (?format=csv):

- /api/v1/votes: voturile pe o lege sau dintr-o perioadă
- /api/v1/laws: drumul unei legi prin cele două camere
- /api/v1/parlamentari: statistici și toate voturile unui parlamentar
- /api/v1/export/{voturi|legi|deputati|senatori}: seturile complete, actualizate zilnic

Acoperă 2 383 de voturi și 423 626 de opțiuni individuale, din 21 decembrie 2024. Documentația: https://la-butoane.ro/api/v1

Dacă vi se pare util pentru comunitate, o mențiune ne-ar ajuta. Primim cu plăcere și feedback tehnic sau cereri de câmpuri noi.

Denis
LaButoane · la-butoane.ro · @la.butoane
